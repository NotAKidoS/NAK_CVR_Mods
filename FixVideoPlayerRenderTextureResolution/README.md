# FixVideoPlayerRenderTextureResolution

Resizes the video player projection texture to match the playing video's native resolution. This should remove some blur and rescaling artifacts (makes things slightly sharper).

By default, the CCK generates a 1080p projection texture, so without this mod, you are scaling most video's to 1080p after internally rendering them at their native resolution.
